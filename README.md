# RNSTYLE Official Site

FigmaのPC / Home（163:2）を基準に、SP / Home（309:2964）、Service、About、Contact、Works、実績詳細、News、Privacyを読み取り、PHP・CSS・JavaScriptで構成したオリジナルテーマです。ビルド作業や必須の有料プラグインはありません。

## 導入

1. `RNSTYLE_OfficialSite` フォルダを `wp-content/themes/` に置く。今回の実装先には配置済みです。別環境では配布ZIPを「外観 → テーマ → 新しいテーマを追加 → テーマのアップロード」から導入できます。
2. WordPress管理画面の「外観 → テーマ」で **RNSTYLE Official Site** を有効化。
3. 「外観 → RNSTYLE 設定」で必要に応じて **初期コンテンツを作成** を押す。既存の同名スラッグは上書きしません。繰り返しても重複作成しません。テーマ有効化だけでデータベースにデモデータを登録することはありません。
4. 「設定 → 表示設定」で「固定ページ」を選び、ホームページを **Home** にする。Newsは独自一覧なので「投稿ページ」には指定不要。
5. 「設定 → パーマリンク」で希望の形式を選び、保存する。例 `/%postname%/`。
6. プライバシーポリシーを開き、内容を確認して公開。WordPress標準のPrivacy下書きが既にある場合、初期作成はその本文・状態を変更しません。Figmaの文章を使う場合は `inc/privacy-content.html` を参考に編集してください。
7. 「外観 → メニュー」でヘッダー／フッターを編集。未指定ならテーマ標準メニューが表示されます。サイトロゴは「外観 → カスタマイズ → サイト基本情報」で設定可能。
8. 「外観 → RNSTYLE 設定」で送信先メールアドレスを設定。空欄はWordPressの管理者メールアドレスを使用します。

## フォーム

会社名・お名前・メールアドレス・電話番号・ご相談内容・同意が必須。役職・URL・予算感・希望納期もFigmaに合わせて実装しています。

- JavaScriptありの場合は画面遷移なしで送信。失敗時は入力内容を保持します。
- JavaScriptなしでも送信可能。入力エラー時は同じ入力内容を戻します。
- サーバー側の必須・形式・長さチェック、nonce、honeypot、IPごとの60秒間隔制限を実装。
- メール送信はWordPress標準 `wp_mail()` を使用。実運用では送信サーバー／SMTPを設定し、受信確認まで実施してください。受け付け表示は送信処理の成功を表し、受信箱への到達保証ではありません。
- 送信者アドレスはサーバー側の設定を使用し、入力メールアドレスはReply-Toに設定。問い合わせ内容をWordPressの投稿やDBには保存しません。サーバー／メールシステムのログとメール保管は別管理です。
- Contactページはフォームnonceの期限を考慮してキャッシュから除外するか、適切な短いキャッシュ期間にしてください。

## デザインと補完した仕様

背景 `#fffefb`、交互背景 `#f5f4f1`、文字 `#111827`、アクセント `#00668c`、CTA `#d4eaf7`。OSのダークモードでもこの配色を維持します。

PCは1440px、SPは375pxを参照。768px未満をSPレイアウトにし、中間幅も可変レイアウトで処理。ヒーローはPC専用の横長画像6レーンと、SP専用の縦長画像3レーンを使用します。Orbit View の画像数に合わせてレーンの一周距離と周期を調整し、レーンごとに開始画像と時差をずらします。画像がない場合は従来のアニメーションを維持します。停止ボタンと端末の動きを減らす設定に対応。

Worksのギャラリーは公開済みの制作実績を手動で回転する構成です。グリッドへ切り替えられ、タグ絞り込みとプレビューに対応。詳細は末尾のv1.1.0の項目を参照。

料金に食い違いがあったためPC / Homeの80万円／50万円を優先。サービス番号の重複など明らかな表記揺れを補正。SP実績カードで繰り返されていた文言はPCの実績内容に統一しました。

Noto Sans JPをローカル同梱。Futura PTはライセンス未提供のため同梱せず、端末にあれば使用し、なければAvenir Next Condensed／Arialへフォールバックします。英字の字形・字幅には差があります。精密な一致が必要な場合はライセンス済みWebフォントへ変更してください。

自社プロダクト一覧は独立した日本語Figma画面がなかったため共通カードで補完。英語コンテンツは自動生成していません。PolylangまたはWPMLがある場合のみ言語切替を表示します。どちらも必須ではありません。

## 公開前の確認

初期実績4件の画像はFigmaの同一サンプル画像です。実績詳細本文とギャラリーは管理画面で実内容を登録してください。公開可否が不明な実績を追加で作成していません。

PrivacyはFigma内の文章を移植しています。元の文章にはGoogle Analytics・Cloudflare Turnstileへの言及がありますが、今回のテーマは両サービスを読み込みません。実際の利用サービスに合わせて該当箇所を編集し、公開する内容を確認してください。

初版の作成時にはテーマ有効化・既存サイト設定変更・既存DBへの初期データ登録・本番公開・外部宛メール送信を実施していません。以降の公開反映は末尾のv1.1.0とQA資料を参照。検証には別のWordPressとSQLiteを使用しています。本番テーマにSQLiteプラグインや検証用メール処理は含めていません。

## 技術情報

PHP 8.1以上・WordPress 6.6以上を想定。検証した組み合わせはQA資料を参照。必須のNode.jsやCSSフレームワークはありません。

`functions.php` でテーマ機能と読み込み、`inc/content.php` で投稿タイプ、`inc/admin.php` で編集画面と初期データ、`inc/contact.php` でフォーム、`assets/css/main.css` でレイアウト、`assets/js/main.js` で操作を管理。見出し等のレイアウト文言は各テンプレートにあります。CPTのデータはテーマを変更してもDB内に残りますが、管理機能はこのテーマに依存します。

Figma画像・SVGは全てローカル保存済み。一時URLへの実行時依存はありません。画像の出典とハッシュは `ASSETS.json`、フォントのライセンスは `assets/fonts/OFL.txt` を参照。

## v1.0.2 カスタマイザーの404修正

Service等の固定ページをまだ登録していない状態でも、カスタマイザー内ではテーマ付属の画面を表示できるようにしました。対象はHome・Service・Works・About・Contact・News・Privacy・Owned Productsのみ。プレビュー専用で、固定ページの追加・公開や既存設定の変更は行いません。存在する公開ページを優先し、その他の存在しないURLは404のままにします。

## 実績連動ギャラリー（v1.1.0）

Worksは公開中の制作実績1件につき1枚を表示します。画像は「制作実績 → RNSTYLE 一覧・回転ギャラリー → 回転・グリッド用サムネイル」で選びます。未指定なら既存カード画像、アイキャッチ、メイン画像の順で使用。画像がなくても実績名を表示します。下書きは表示しません。

同じACFグループで「絞り込みタグ」「ポップアップの紹介文」「仮実績として表示」を編集できます。タグはカンマまたは改行で区切り、公開実績で使われているタグだけがALLの横に並びます。ラベルは自由ですが、フィールド名・キーは変更しないでください。既存のACF設定は更新で上書きしません。

左右ドラッグ／スワイプ、矢印キー、Home／Endで回転します。サムネイルをクリックすると画像・紹介文・タグ・年のプレビューが開き、「実績詳細を見る」から詳細へ移動。Esc、閉じる、背景クリックで閉じます。プレビュー内の前後ボタンは絞り込み中の実績を巡回します。グリッドへ切り替えても同じ画像・絞り込みを使います。Worksのページ送りと別立ての重複サムネイル一覧は廃止しました。

タグと表示モードは `work_tag` と `view=grid` のURLに反映します。絞り込み後の再読み込み・共有に対応。JavaScriptが無効な場合はサムネイルから詳細へ直接移動し、タグと切り替えは通常リンクで動作します。

新規導入ではACF有効化後、「外観 → RNSTYLE 設定 → ACFの一覧編集欄を追加」を1回実行するか、`config/acf-gallery-field-group.json` のみインポートします。既存グループを再インポートする必要はありません。

「本サイトと不足分の仮実績を登録」は本サイトを含めて公開実績が合計7件になるまで追加します。画像IDを空欄にすると付属の実サイトキャプチャをメディアへ取り込みます。既存の投稿・入力値は変更せず、同じ仮実績を重複作成しません。追加分はSAMPLEラベル付き。仮実績はACFで編集し、不要になったものは下書きへ戻せます。

## 実績ごとの背景色（v1.1.1）

「制作実績 → RNSTYLE 実績の基本情報 → 詳細ページの背景色」で、実績ごとに色を選んで保存できます。カラーコードの直接入力にも対応。空欄なら従来の背景色に戻ります。詳細本文とヘッダーに適用し、共通CTA・フッターは既存のブランド配色を維持します。

`.case-figure img` は最大幅900pxで中央配置。画面が狭い場合は親要素の幅に合わせて縮小し、縦横比を保持します。既存の画像や本文は変更しません。

既存サイトのフィールド追加は実施済み。新規環境では同梱のACF定義に含まれます。背景色を変更していない実績の見た目は従来どおりです。

## ヘッダーロゴ（v1.1.4）

ヘッダーは `assets/images/logo-black.svg` を108×21pxで表示します。使用する画像は `functions.php` の `rn_header_logo()` 内にある `rn_asset('logo-black.svg')` で指定しています。

ロゴを差し替える場合は、新しい画像と、参照先を変更した `functions.php` を公開サーバーの同じテーマへアップロードしてください。ローカルに保存するだけでは公開サイトには反映されません。`ASSETS.json` は画像の一覧・出典・ハッシュを記録する資料です。このファイルの変更だけでは、ヘッダーの表示画像は切り替わりません。

## 実績詳細のタイトルとアニメーション（v1.2.1）

ACFの導入用タイトルをh1.case-titleの位置に常設し、PC/SPとも画面幅に合わせて1行に収めます。ON／OFFはアニメーションだけを切り替えます。タイトルが空欄なら投稿タイトル、文字色が空欄なら背景に合う色を使用します。

## トップのオープニング（v1.3.0）

後ろ回転版の黒いMacBook動画をトップページのみに表示します。再生終了後は #FFFEFB の画面を1秒保持し、実際のページを1.6秒でフェード表示。確認動画に含まれる静止ページ画像は再生しません。

## オープニングのセッション制御（v1.3.1）

同じタブのセッションでは初回だけ再生します。sessionStorage の `rnstyle-opening-seen` をページを隠す前に記録するため、通常のページ移動からトップに戻る場合、再読み込み、再生途中の再読み込み、スキップ後の再訪では本文をすぐ表示し、動画ソースを読み込みません。新しいタブのセッションでは再生可能です。永続CookieやlocalStorageは使用しません。

ストレージの読み書きが制限されている場合も、本文をすぐ表示します。初回の映像、#FFFEFBの1秒保持、1.6秒のフェード、既存の省略条件は維持。投稿・ACF値の変更は不要です。

## URL共有時の画像（v1.3.2）

サイト共通のOGP画像は `assets/images/ogp-rnstyle.png`（ユーザー指定PNG、3600×1890px、58,722 bytes）です。トップ・固定ページ・制作実績で同じ画像を使います。

次回画像を差し替えるときは、PNGと `inc/social.php` の寸法を揃え、新しい画像ファイル名を使ってください。ロリポップ！アクセラレータのページキャッシュは通常約10分保持されるため、更新時にはキャッシュ削除か保持時間後の通常URLで確認してください。
